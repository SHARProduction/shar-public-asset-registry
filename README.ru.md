# Канонический реестр публичных активов SHAR Production

`SHAR_PUBLIC_ASSET_REGISTRY` — машиночитаемый перечень подтверждённых публичных активов **[SHAR Production](https://sharprod.com/)**. Версия схемы: `1.0.0`. Последнее обновление доказательств: `2026-09-05T21:41:58Z`. В реестре: 64 активов.

Канонический источник — `data/registry.json`. `README.md`, `README.ru.md` и `STATUS.md` являются производными проекциями и создаются командой `npm run generate`.

## Принципы

- `asset_id` неизменяем и не зависит от текущего URL, версии или статуса.
- `PUBLISHED_VERIFIED` допустим только после проверки точного публичного URL, владельца, содержимого или функции и конкретной версии.
- HTTP 200 без проверки содержимого или функции недостаточно.
- Публикация не считается доказательством индексации, цитирования, использования, обучения моделей или коммерческого эффекта.
- После переноса репозитория immutable ID сохраняется, а namespace, URL, версия и evidence обновляются.

## Проверка

`npm run check` проверяет контракт, уникальность immutable ID, evidence gates, покрытие scope и воспроизводимость всех проекций.

Перед обновлением выполните read-only проверки провайдеров, запишите точный UTC timestamp и неизменяемую версию. Не повышайте статус по старой записи, перенаправлению, заглушке или одному коду HTTP.
