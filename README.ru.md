# Канонический реестр публичных активов SHAR Production

`SHAR_PUBLIC_ASSET_REGISTRY` — машиночитаемый перечень подтверждённых публичных активов **[SHAR Production](https://sharprod.com/)**.

Канонический источник — `data/registry.json`. `README.md` и `STATUS.md` являются производными проекциями и создаются командой `npm run generate`.

## Принципы

- `asset_id` неизменяем и не зависит от текущего URL, версии или статуса.
- `PUBLISHED_VERIFIED` допустим только после проверки точного публичного URL, владельца, содержимого или функции и конкретной версии.
- HTTP 200 без проверки содержимого или функции недостаточно.
- Неподтверждённые условия не заменяются предположением: итог проверки становится `PARTIAL`, а операционный статус понижается.
- Публикация не считается доказательством индексации, цитирования, использования, обучения моделей или коммерческого эффекта.
- Репозитории того же личного аккаунта без подтверждённой связи с SHAR Production не включаются.

## Проверка

```sh
npm run check
```

Команда проверяет контракт, уникальность immutable ID, evidence gates, точное покрытие текущего scope и воспроизводимость проекций.

## Обновление

Повторите read-only проверки провайдеров, запишите точный UTC timestamp и неизменяемую версию, сохраните доказательные детали, затем запустите генератор и тесты. Не повышайте статус по старой записи, перенаправлению, заглушке или одному коду HTTP.
